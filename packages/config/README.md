# @famir/config

[![npm version](https://img.shields.io/npm/v/@famir/config.svg)](https://www.npmjs.com/package/@famir/config)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

Load and validate configuration.

## Features

- Single point of assembly for config parts distributed across packages.
- Obtaining config data through environment variables.
- Parses config only on first use (lazy loading).
- Integration with other packages of the ecosystem.
