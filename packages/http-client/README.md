# @famir/http-client

[![npm version](https://img.shields.io/npm/v/@famir/http-client.svg)](https://www.npmjs.com/package/@famir/http-client)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

Robust HTTP client with graceful exception handling

## Features

- High-performance **node-libcurl** as backend HTTP Client.
- Multiple operating modes - simple, streaming request and streaming response.
- Friendly with curl-impersonate to bypass TLS fingerprint checks.
- Clear error handling with `HttpClientError`.
- Integrated with other packages of the ecosystem.
