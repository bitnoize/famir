# @famir/logger

[![npm version](https://img.shields.io/npm/v/@famir/logger.svg)](https://www.npmjs.com/package/@famir/logger)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

Structured logging service

## Features

- TypeScript-first with strict type guards and assertions
- Configuration via `@famir/config` package
- Six log levels: trace, debug, info, warn, error, fatal
- Structured logging with key-value pairs
- **Pino** backend for high performance
- Integration with `@famir/common` DI container
