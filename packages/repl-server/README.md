# @famir/repl-server

[![npm version](https://img.shields.io/npm/v/@famir/repl-server.svg)](https://www.npmjs.com/package/@famir/repl-server)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

REPL server infrastructure service.

## Features

- TypeScript-first with strict type guards and assertions
- Configuration via `@famir/config` package
- Native **node:repl** as backend REPL Server
- `Cli` and `Net` implementations for various uses
- Clear error handling with `ReplServerError`
- Structured logging with `@famir/logger` package
- Integration with `@famir/common` DI container
