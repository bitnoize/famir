# @famir/templater

[![npm version](https://img.shields.io/npm/v/@famir/templater.svg)](https://www.npmjs.com/package/@famir/templater)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

A lightweight template rendering tool for the Famir ecosystem.

## Features

- TypeScript-first with strict type guards and assertions
- Simple `render(template, data)` API
- Powered by the **Eta** template engine
- Clear error handling with `TemplaterError`
- Integration with `@famir/common` DI container
